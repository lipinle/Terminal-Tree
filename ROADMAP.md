# Roadmap

Priority is data integrity and reliable daily use, not adding features for their own sake.

- 2.1: consolidate patches and preserve history; establish tests and installation workflow.
- 2.2: strengthen file-operation tests, real Trash integration, crash recovery and verification; review remaining race conditions.
- 2.3: benchmark large directories, HDD and SSD performance; improve caching and progress/cancellation.
- 2.4: themes, configurable keyboard controls and usability.
- 2.5: opt-in versioned update workflow and release packaging.
- 2.6: broader shell and Linux distribution compatibility.
- 3.0: stable release after acceptance and safety testing.

Versions beyond 2.1 are planned, not implemented.
